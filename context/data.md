# Data
Video key: slug. Metadata: title, date, tags, contentTags, promptShared, creator handle/avatar, poster/preview/full-video URLs, width/height, optional prompt/skillUrl/tweetUrl/model/stack/effort/iterations.
Creator handles and avatars are public attribution data; they are returned for credit. No private account data is fetched.
Primary category is the first recognized content tag; neighbours follow newest-first order in that category.
Directory entry key: id, with name, description, category, url and cover. Existing MCP sections: tools and studios.
Search is AND over lowercased words in title, handle, prompt and contentTags; directory search is AND over name, description and category. No semantic search is claimed.
